# Beton-Instandsetzung Dashboard

Interaktive Streamlit-App zur Analyse und Visualisierung von Betoninstandsetzungs- und Schadensdaten im Bauwesen.

## 🚀 Features
- Auswertung von Schadensdaten
- Filter nach Baujahr, Bauteil oder Projekt
- Interaktive Visualisierungen
- Einfache Weboberfläche mit Streamlit

## 🧱 Anwendungsbereich
Dieses Tool richtet sich an:
- Bauleiter
- Bautechniker
- Fachplaner für Betoninstandsetzung

## ⚙️ Installation

```bash
pip install -r requirements.txt
streamlit run app.py
